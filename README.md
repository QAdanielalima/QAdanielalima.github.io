# 🌐 Portfólio Profissional - Daniela Lima (QA Tester)

Este repositório contém o código-fonte do meu portfólio profissional, desenvolvido para apresentar meus projetos, competências e experiência na área de **Garantia da Qualidade de Software (QA)**.

🔗 **Acesse o portfólio online:** [qadanielalima.github.io](https://qadanielalima.github.io/)

## 🎯 Sobre o Projeto

O objetivo deste site é centralizar meus casos de teste, projetos de automação e relatórios de qualidade em um só lugar, permitindo que recrutadores e equipes técnicas avaliem minha metodologia de trabalho de forma clara e acessível.

### 🛠️ Tecnologias e Recursos Utilizados
- **HTML5 & CSS3:** Estrutura semântica e estilização moderna.
- **JavaScript:** Interatividade, filtros de projetos e dinamismo na interface.
- **Acessibilidade Web (WCAG):** Foco em navegação por teclado, leitores de tela e marcação ARIA.
- **GitHub Pages:** Hospedagem e deploy contínuo da aplicação.

---

## 📂 Funcionalidades do Portfólio
- 🎯 **Apresentação Profissional:** Resumo da minha trajetória, foco de atuação e perfil profissional.
- 🧪 **Filtro de Projetos por Contexto:** Visualização organizada de testes aplicados em Web, Mobile e API.
- 📱 **Design Responsivo:** Adaptado para navegação em dispositivos móveis e desktops.
- ♿ **Acessibilidade:** Atalhos de navegação para facilidade de uso.
